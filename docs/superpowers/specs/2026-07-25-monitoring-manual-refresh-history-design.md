# 手动刷新保留同日历史

## 目标

发布效果监测的每次成功手动刷新都保留一条快照，即使发生在同一天；用户可以在图表中看到同日多次更新的实际采集时间。

## 行为

- 新建任务的首次成功采集写入第一条快照。
- “立即更新”每成功一次就追加一条快照，不再覆盖当天已有快照。
- 定时任务仍以“当天尚未采集”为准，每天最多自动采集一次；启动补采也遵循该规则。
- 指标卡继续取最新快照，趋势图按完整采集时间排序并展示所有同日采集点。
- 采集失败不追加快照，保留既有历史并更新失败信息。

## 实现与验证

- 服务层只移除刷新时的同日快照替换逻辑，不改变 `is_due` 的自动任务去重规则。
- 用例覆盖：同日两次手动刷新后保留两条快照，且后一条为最新数据；自动采集仍不会在同日重复触发。
